# Dabsky 3D app media

Place `dabsky-icon.png` and `dabsky-menu-loop.ogv` in this folder.

`dabsky-icon.png` is the Dabsky emblem used for the menu and Android launcher icon. `dabsky-menu-loop.ogv` must be Theora-encoded, silent and slowed; the menu loops it while visible.

The GitHub Actions Android workflow automatically builds and signs new main-branch commits with the existing permanent Dabsky signing secrets. Keep the keystore private; never add it here.
